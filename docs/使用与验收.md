# Model 0.17 使用与验收

## 交付边界

本包包含同一提交构建的 Windows Runtime EXE、内置网页、官方 CPU llama.cpp 引擎、源码、模型准备 Notebook、自动测试与验收文档。模型权重不包含在安装包内，仍以 Google Drive 为主库。

这不是“全部模型和你的电脑都已验收通过”的声明。CPU 真实模型测试、源码合同测试、浏览器测试、你的 Drive 授权、GPU 实测是不同的证据层次。查看 `qa-evidence` 中对应 JSON；没有证据的项目不得标记完成。

## 首次安装

1. 将 ZIP **完整解压**，不要在压缩文件预览窗口直接运行。
2. 运行 `runtime/Install.cmd`。默认缓存路径保留为 `D:\Model`；已有配置会继续使用。没有 D 盘时，可用 PowerShell 执行 `runtime/install_runtime.ps1 -CacheRoot "C:\Model"` 指定现有磁盘，不会自动清空其他目录。
3. 新安装会使用包内的官方 CPU llama.cpp 引擎。此前已配置且仍存在的 llama-server 会被保留；不强制替换用户自选 CUDA 引擎。
4. 安装后打开 `http://127.0.0.1:8765/`。网页由该 EXE 内置，不依赖 GitHub Pages 是否已合并新版本。以后也可以双击托盘图标打开。
5. 访问 `/health` 应看到 `version: 17`。安装包中的 `EXE_SHA256.txt` 与 `runtime/llama/BUNDLE.json` 用于核对可执行文件和引擎来源。

这次提供的是个人项目构建，不是带商业代码签名和厂商支持承诺的安装程序。不要通过关闭系统安全功能处理来源不明的同名 EXE。

## Google Drive 登录：必须区分源码修复与线上部署

网页依赖现有 Cloudflare OAuth Worker。仓库旧源码只允许旧 Model 回调，并把所有浏览器会话指向一个全局 `refresh_token`。0.17 的 `workers/drive-oauth-bridge.mjs` 已修复为：

- 允许当前 `Jvust/Model` 和本机网页的明确回调地址；
- HMAC 签名状态 Cookie，加上 PKCE；
- 每个浏览器会话保存自己的加密刷新令牌，不读取旧的全局令牌；
- 会话绑定前端 Origin，支持单独注销；
- Google 的访问令牌只临时传给 Runtime，不能写入仓库或模型文件。

**修改 GitHub 文件不会自动部署 Cloudflare Worker。** 需要账户所有者把该文件部署到现有 `drive-oauth-bridge` 服务，保留原有 `OAUTH_KV` 绑定、`GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET` 和 `REDIRECT_URI`。不要把这些值发到聊天或写进 GitHub。

部署 v2 后，旧的全局令牌会话应重新登录一次；这不会删除 Drive 文件。Worker 根地址应返回 `version: 2`。`qa-evidence/oauth-public-probe.json` 只是未登录的公共端点探测，不是已经访问你的 Drive 的证明。若探测仍显示旧版或失败，Drive 登录上线仍未完成。

## 一次准备六个 CPU 模型

打开 `notebooks/Prepare_Models.ipynb`，使用 **CPU** Colab 运行时。六个开关分别控制聊天、Embedding、Reranker、GOT-OCR、Chronos、TimesFM。

先运行配置单元，查看实际仓库提交和预计大小；再运行下载单元。每个仓库固定到当次解析出的提交，验证文件大小和可获得的 LFS SHA256，写出 `MODEL_READY.json`。已有正确文件由 Hugging Face 下载器复用。

## 各工作区

**聊天。** 从模型库启动 GGUF。在“聊天模型独立参数”中按模型保存上下文、CPU 线程、GPU 层数和加载方式，下次启动生效。Qwen 默认 4096 上下文，DeepSeek/Coder/写作默认 8192；这些是界面默认值，不是机器一定承受得住的保证。显存不足时不要盲目增加 GPU 层数。

**Embedding / Reranker。** 使用独立 8091 端口，不替换聊天端口 8080。Embedding 每行一条文本；Reranker 输入查询和候选文档。结果可以导出完整 JSON，向量不会只剩界面里的预览。

**GOT-OCR。** 使用原生 HF 版本，拒绝需要任意自定义代码的旧模型包。上传 PNG/JPEG/WebP，最大 8 MB。CPU 测试证明真实模型能够加载并输出文字，不代表所有中文、表格和图片均准确。已有测试输出出现重复文字，原始结果保留在证据中，未用后处理掩盖。

**Chronos / TimesFM。** 输入 16–2048 个有限数值，或提供 CSV 与数值列名；不静默截断数据，也不接受缺失值、NaN 和无穷大。输出 1–256 个相对预测步。Chronos 可返回模型分位数；TimesFM 返回点预测。这不是收益承诺，也不是已校准置信区间。

**图像。** Pony、Qwen-Image、FLUX.2 使用各自固定模型文件和 ComfyUI 图。缺权重/companion 时仍阻止启动。FLUX.2 现有主权重不应被重复下载，其依赖准备器保留在旧有 Drive notebook_launchers 中。

**视频。** 已有 Wan TI2V/Hunyuan ComfyUI 路线保留，完整 Wan2.2 T2V/I2V Diffusers 包另有原生工作区。A14B 分片包不是可直接交给单文件 UNETLoader 的 checkpoint。现有 AMD Vega 8 不能作为这些 NVIDIA 路线的验收设备。

## 远程 NVIDIA

在另一个合适的 NVIDIA Windows 主机安装 Runtime，使用仓库的 `Enable-Remote-Nvidia.cmd` 配置 Tailscale Serve。Runtime 本身仍监听 loopback，不开放到公网。

在当前电脑的本机网页中，将 Runtime URL 设置成该主机的私有 HTTPS 地址并填写令牌。推荐继续从本机网页登录 Drive，而不是把未列入 OAuth 回调清单的任意远程域名当作前端登录地址。

源代码、HTTP 鉴权测试和 PowerShell 自检不能替代真实双机测试。验收时必须检查 Drive 会话同步、模型进度以及鉴权后的图像/视频读取。

## 缓存、停止与故障

- 首次读取完整模型后持久保存在所配置缓存目录；后续复用，不自动清理。
- 用户取消任务不会把已有完整权重当临时文件删除；部分下载由缓存器保留以便续传。
- 模型包使用同卷硬链接，缓存盘应支持此能力；不在不支持时偷偷复制数十 GB。
- Native 任务日志位于缓存下 `native/jobs/<job_id>/worker.log`；环境安装日志在 `native/environments/<key>/setup.log`。
- 缺配置、缺分片、错误模型族、硬件不足或安装依赖失败会显示具体失败，不回退到其他模型制造“成功”。
- 远程媒体结果也要认证。更新后不能继续依赖旧版未认证媒体 URL。

## 发布前最后验收

正式标记整个项目完成前，仍需所有者确认：Cloudflare v2 已部署并完成实际 Drive 授权；在目标电脑跑通真实 Drive 冷缓存/断点恢复/热缓存；在 NVIDIA 主机完成真实图像、视频和双机 HTTPS 测试；审阅并明确合并 PR。

验收证据必须保留输入摘要、源模型提交、输出、设备环境与是否经过真实 Drive。不要把 CI 使用官方临时权重的结果写成“已经在用户电脑和 Drive 上运行”。
